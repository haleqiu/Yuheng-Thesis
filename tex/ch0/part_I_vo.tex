\begin{center}
\textit{Mammalian spatial perception begins with vision, which provides rich external scene structure. Analogously, this part establishes metrics-aware visual uncertainty as the first foundation. \textbf{MAC-VO} learns 2D matching uncertainty and propagates it into full 3D covariance with inter-axis correlations, replacing hand-tuned noise models for keypoint selection and residual weighting in learning-based stereo visual odometry. \textbf{QuantMAC-VO} then demonstrates that this learned uncertainty pipeline can be compressed for real-time edge deployment via sim-to-real calibration and kurtosis-based hybrid quantization, with negligible accuracy loss. Together, these chapters show that visual uncertainty can be learned in metric space, used in real estimators, and deployed efficiently on edge hardware.}
\end{center}
