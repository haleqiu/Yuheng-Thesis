\section{Summary of Contributions}

This dissertation has presented a comprehensive approach to learning-based SLAM that advances toward fully automated spatial AI systems. The key contributions include:

\begin{itemize}
    \item MAC-VO: A metrics-aware approach to uncertainty estimation in stereo visual odometry
    \item AirIO: Learning-based inertial odometry with enhanced feature observability
    \item AirDOS: Leveraging dynamic object understanding for improved SLAM
    \item A framework for foundation model integration in spatial intelligence systems
\end{itemize}
